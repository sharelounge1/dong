**프로젝트명**: 또리(TORI) - 현지 친구와 함께하는 여행 동행 플랫폼
**버전**: 1.0
**최종 수정일**: 2025-01-18

## 1. 인증 화면

### 1.1. SplashScreen (스플래시)

| 항목 | 내용 |
|------|------|
| **화면 ID** | AUTH-001 |
| **경로** | `/` (초기 진입) |
| **목적** | 앱 로딩 및 인증 상태 확인 |

**UI 구성**
- 로고 이미지 (중앙)
- 로딩 인디케이터
- 브랜드 슬로건 텍스트

**프로세스**
1. 앱 시작 → 로고 표시
2. 토큰 유효성 검증
3. 유효한 토큰 → HomeScreen 이동
4. 토큰 없음/만료 → OnboardingScreen 또는 LoginScreen 이동
5. 최초 방문자 → OnboardingScreen, 재방문 → LoginScreen

### 1.4. SignupScreen (회원가입)

| 항목 | 내용 |
|------|------|
| **화면 ID** | AUTH-004 |
| **경로** | `/auth/signup` |
| **목적** | 신규 회원 정보 입력 |

#### Step 1: 기본 정보 (SignupBasicScreen)

**입력 필드**
| 필드 | 타입 | 필수 | 검증 |
|------|------|------|------|
| 닉네임 | text | O | 2-20자, 특수문자 불가 |
| 나이 | number | O | 18-100 |
| 성별 | select | O | 남성/여성/기타 |
| 국적 | select | O | 국가 목록 |

#### Step 2: 프로필 (SignupProfileScreen)

**입력 필드**
| 필드 | 타입 | 필수 | 검증 |
|------|------|------|------|
| 프로필 사진 | image | O | 최대 5MB, JPG/PNG |
| 거주 도시 | search | O | 도시 검색 선택 |
| 자기소개 | textarea | X | 최대 500자 |
| 추가 사진 | images | X | 최대 5장 |

#### Step 3: SNS 연동 (SignupSnsScreen)

**입력 필드**
| 필드 | 타입 | 필수 | 검증 |
|------|------|------|------|
| 카카오톡 ID | text | △ | 최소 1개 필수 |
| 라인 ID | text | △ | 최소 1개 필수 |
| 왓츠앱 ID | text | △ | 최소 1개 필수 |

**안내 문구**
> "친구 검색 허용 설정을 열어두셔야 상대방이 연락할 수 있습니다."

#### Step 4: 언어/취미 (SignupInterestScreen)

**입력 필드**
| 필드 | 타입 | 필수 | 검증 |
|------|------|------|------|
| 사용 언어 | multi-select | O | 최소 1개 |
| 취미/관심사 | tags | O | 최소 1개 |

**취미 태그 옵션**
- 맛집탐방, 카페투어, 쇼핑, 사진촬영, 나이트라이프, 관광, 액티비티, 문화체험

**프로세스**
1. 각 단계 입력 완료 → "다음" 클릭
2. 필수 항목 미입력 시 에러 표시
3. Step 4 완료 → TermsAgreementScreen 이동

## 3. 동행 요청 화면

### 3.1. RequestCreateScreen (요청글 작성)

| 항목 | 내용 |
|------|------|
| **화면 ID** | REQ-001 |
| **경로** | `/request/new` |
| **목적** | 동행 요청글 등록 |

#### Step 1: 여행 정보

**입력 필드**
| 필드 | 타입 | 필수 | 설명 |
|------|------|------|------|
| 여행지 | search | O | 도시 검색 선택 |
| 세부 지역 | text | X | 특정 구역 |
| 시작일 | date | O | 캘린더 선택 |
| 종료일 | date | O | 캘린더 선택 |
| 인원 | number | O | 1-10명 |

#### Step 2: 희망 동행자 조건

**입력 필드**
| 필드 | 타입 | 필수 | 설명 |
|------|------|------|------|
| 연령대 | range | X | 최소-최대 나이 |
| 성별 | select | X | 남성/여성/상관없음 |
| 국적 | select | X | 특정 국적/상관없음 |
| 사용 언어 | multi-select | O | 최소 1개 |

#### Step 3: 활동 및 팁

**입력 필드**
| 필드 | 타입 | 필수 | 설명 |
|------|------|------|------|
| 희망 활동 | multi-select | O | 맛집, 카페, 쇼핑 등 |
| 팁 금액 | number | O | 하루 기준 (원) |
| 통화 | select | O | KRW/JPY/USD |

**팁 안내 문구**
> "팁은 동행자에게 직접 전달하는 감사 비용입니다. 플랫폼 수수료와 별개입니다."

#### Step 4: 추가 정보

**입력 필드**
| 필드 | 타입 | 필수 | 설명 |
|------|------|------|------|
| 추가 사진 | images | X | 최대 5장 |
| 설명 | textarea | X | 최대 1000자 |
| 여행객 공개 | checkbox | X | 다른 여행객에게도 공개 |

**프로세스**
1. 모든 단계 입력 완료
2. "등록하기" 클릭
3. 요청글 저장
4. 성공 팝업 표시
5. MyRequestsScreen 이동
6. 관련 사용자에게 푸시 알림 발송

### 3.3. ApplicantListScreen (신청자 리스트)

| 항목 | 내용 |
|------|------|
| **화면 ID** | REQ-003 |
| **경로** | `/request/:requestId/applicants` |
| **목적** | 해당 요청의 신청자 목록 확인 |

**UI 구성**

**신청자 카드**
- 프로필 사진 (작게, 블러 처리)
- 나이/성별/언어 (공개 정보)
- 신청 요약 (첫 2줄)
- 신청일
- "상세 보기" 버튼

**안내 문구**
> "상세 프로필 열람 시 포인트가 차감됩니다."

**프로세스**
1. "상세 보기" 클릭
2. **과금 안내 팝업 (M-101)** 표시
   - "상세 프로필 열람 시 {n}P가 차감됩니다"
   - "확인" / "취소"
3. 확인 → 포인트 부족 시 **포인트 부족 팝업 (M-103)** 표시
4. 포인트 충분 → 차감 후 ApplicantDetailScreen 이동

### 3.4. ApplicantDetailScreen (신청자 상세)

| 항목 | 내용 |
|------|------|
| **화면 ID** | REQ-004 |
| **경로** | `/request/:requestId/applicants/:applicantId` |
| **목적** | 신청자 상세 프로필 및 승인/거절 |

**UI 구성**

**프로필 섹션**
- 프로필 사진 (전체 크기)
- 닉네임, 나이, 성별
- 국적, 거주 도시
- 사용 언어
- 취미/관심사 태그
- 자기소개
- 추가 사진 갤러리

**신청 내용 섹션**
- 가능한 날짜/시간
- 가능한 활동
- 신청자 메시지

**평점/후기 섹션** (있는 경우)
- 평균 별점
- 최근 후기 3개

**하단 버튼**
- "동행 승인하기" (Primary)
- "거절하기" (Secondary)

**프로세스**

**승인 시**
1. "동행 승인하기" 클릭
2. **승인 과금 안내 팝업 (M-102)** 표시
   - "승인 시 {n}P가 차감되며 SNS ID가 상호 공개됩니다"
3. 확인 → 포인트 차감
4. 매칭 생성 (status: pending_confirmation)
5. 신청자에게 승인 알림 발송
6. **매칭 성사 팝업 (M-201)** 표시
7. MatchDetailScreen 이동

**거절 시**
1. "거절하기" 클릭
2. 거절 사유 선택 (선택적)
3. 신청 상태 업데이트
4. 신청자에게 거절 알림 발송
