🎯 1. 서비스의 큰 목표 및 비즈니스 모델 요약
1.1. 서비스의 큰 목표 (Vision)

핵심 목표
여행객에게는

현지인의 시각이 담긴 안전하고 특별한 여행 경험을 제공하고,

현지 거주자에게는

여행객과 여행의 즐거움을 나누면서 **합당한 감사 비용(팁)**을 얻을 수 있는
프리미엄 동행 플랫폼을 만드는 것.

가치 제안 (Value Proposition)

기존 동행 서비스의 문제(막연한 만남, 신뢰성 부족, 단순 관광)를 줄이고,

친구를 만나는 느낌의 ‘또리(현지 친구) 동행’ 문화를 만들며,

명확한 환불 규정과 동의 절차를 통해 책임 소재와 금전 흐름이 투명한 구조를 제공.

1.2. 비즈니스 모델 (BM) 및 수익 구조

핵심 모델

여행 동행을 원하는 동행 요청자(주로 여행객) 와

동행을 제공하는 현지 거주자(또는 같은 여행지의 다른 여행객) 사이의
정보 공개·매칭·만남 진행을 중개하면서
정보 열람 / 매칭 승인 시점에 과금하는 구조.

주요 수수료(과금 지점)

상세 프로필 열람 비용

동행 요청자가 “신청자 리스트”에서
특정 신청자의 상세 프로필로 들어갈 때 발생하는 비용.

리스트에서는 간단 정보+사진만 보이고,
상세 정보 보기 전에 포인트 차감 안내 → 결제.

동행 승인 매칭 비용

동행 요청자가 마음에 드는 신청자를 **“최종 승인”**할 때 발생.

승인 후, 양측에게 서로의 SNS ID(카카오톡/라인/왓츠앱) 가 공개되며
이 시점이 사실상 매칭 성사 시점.

포인트 & 정산 방식

포인트 선충전 → 열람/승인 시 포인트 차감.

남은 포인트는 출금 요청 → 관리자 승인 후 현금 지급 가능.

출금/환불에 대한 수수료 및 정책은 별도의 약관으로 명시.

관리자 권한

어드민 페이지에서

프로필 열람 비용

매칭 승인 비용
을 성별별로 각각 조정 가능 (남/녀 단가 다르게 세팅 가능).

결제 취소·환불 처리 기능 보유.

2.2. 서비스 전체 흐름(큰 모델)

회원가입 & 프로필 작성

SNS 간편 로그인 → 언어/국적/취미/SNS ID 등 입력.

여행지 선택, 일정, 인원, 원하는 조건, 팁 비용 등 입력 → 요청글 등록.

동행 신청 (현지/여행객 응답 흐름)

① 상세 프로필 열람(과금 1) →
② 승인(과금 2) →
SNS ID 상호 공개 → 매칭 성사.

만남 진행 & 종료

SNS로 연락 → 실제 만남 진행

현지 동행자가 ‘만남 진행됨’ 버튼 →
요청자의 ‘안 만났음’ 여부에 따라 환불/패널티/종료 처리.

2.5. 과금 & 정보 공개 로직

과금 지점은 두 단계

신청자 상세 프로필 열람 시 과금

신청자 목록 → 특정 신청자 카드 클릭 시

“상세 프로필 열람 시 포인트가 차감됩니다” 팝업 노출

확인 → 포인트 차감 → 다음 화면에서

전체 프로필

취미/성향

추가 사진

신청 내용 전체 표시.

동행 승인 시 과금

상세 프로필 화면에서 “승인하기” 버튼 클릭

“이 신청자를 승인하면 추가 포인트가 차감되며, SNS ID가 상호 공개되고 매칭이 성사됩니다.”

확인 → 포인트 차감 → 승인 상태 변경

승인 정보가 신청자에게 전달되고, 양측 SNS ID 공개.

2.6. 동행 승인 후 30분 로직 (1차 유효성 확인)

요청자가 신청자를 승인하면,
→ 신청자에게 “승인 알림” 전송.

신청자는 30분 이내에 ‘승인 거절’ 버튼을 누를 수 있음.

30분 이내 거절
→ 매칭 취소
→ 승인 시 발생했던 과금 전액 환불

30분 동안 아무 행동 없으면
→ “자동 승인 유지”로 보고 매칭 유지
(여기 부분은 원래 “자동 거절 + 환불” vs “자동 승인” 두 버전이 있었는데,
‘매칭이 깨지지 않고 유지되는 쪽이 자연스러워서 자동 승인 유지 쪽으로 정리해도 되고,
만약 원래 의도대로라면 “30분 지나면 자동 거절 + 전액 환불”로 명시할 수도 있음.)

👉 여기서는 사용자 편의성과 서비스 매출을 고려해 “자동 승인 유지” 버전을 쓰고,
문서에 “정책에 따라 자동 거절+환불로 조정 가능” 이라고 남겨두는 것도 방법.

2.7. 만남 진행 & 환불 로직 (2차 확정)

이 부분이 서비스 신뢰도와 직결되는 핵심 로직.

매칭 성사 후, 실제 만남이 진행되면

현지 동행자(Local) 가 앱에서
→ “만남 진행됨” 버튼 클릭.

이때, 동행 요청자(Traveler) 쪽에서

30분 동안 “안 만났음” 버튼 활성화.

요청자 행동 시나리오

ⓐ 30분 이내에 “안 만났음” 버튼 클릭

해당 매칭에 대해 50% 환불

현지 동행자에게 패널티 1점 부과

매칭 상태 = “노쇼/불발”

ⓑ 30분 동안 아무 입력 없음

자동으로 “만남 완료” 처리

이후 환불 불가

후기를 남길 수 있는 상태로 전환

잘못 눌렀을 경우 예외 처리

요청자가 실수로 “안 만났음”을 눌렀는데 실제로는 만난 상태라면
→ 해당 매칭 상세 페이지에 “다시 만남으로 변경” 버튼 제공
→ 이미 환불된 50% 금액을 재결제
→ 만남 상태로 변경, 패널티도 취소 처리 가능(정책에 따라).

2.8. SNS 추가/연락 불가에 따른 환불 규정

추가적인 환불 조건 (매칭 초기 단계에서의 문제 대응)

SNS 추가가 전혀 안 되는 경우

상대방 ID가 틀렸거나, 친구 추가 허용이 막혀 있는 등

앱 내에서 “SNS 추가 불가” 신고 → 운영자 검토 후 전액 환불.

매칭 후 30분 동안 상대방으로부터 연락이 전혀 없는 경우

“연락 없음” 신고 → 전액 환불

필요 시 상대방 패널티 정책과 연동 가능.

만남 자체가 성사되지 않은 경우 (일정 변경 등으로 취소)

합의된 취소이거나, 시스템상 “만남 전 취소”일 경우
→ 50% 환불 정책 적용 가능 (정책에 따라 조정).

이 규정은 이용약관·취소/환불 정책 페이지에 명확히 노출되어야 함.
